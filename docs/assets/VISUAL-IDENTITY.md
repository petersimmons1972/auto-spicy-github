# Visual Identity: auto-spicy-github

## Theme
Dot-com era precision remastered: the angular confidence of an F-117 stealth panel rendered in Y2K electric blue and chrome — the aesthetic of companies that were absolutely going to change everything, built for engineers who actually will.

## Palette
| Role           | Hex       | Usage                                          |
|----------------|-----------|------------------------------------------------|
| Background     | `#080c14` | Near-black with blue undertone — all surfaces  |
| Surface        | `#0e1520` | Slightly lighter — card/panel backgrounds      |
| Primary text   | `#e2eaf6` | Cool white — headings, key values              |
| Secondary text | `#7a9ab8` | Muted steel blue — body text, descriptions     |
| Muted          | `#3d5068` | Dark steel — captions, footnotes, borders      |
| Accent         | `#0af0c8` | Electric teal — calls to action, highlights    |
| Chrome         | `#a8bcd0` | Cool silver — labels, secondary data, dividers |
| Warning        | `#f06020` | Dot-com orange — badges only, use sparingly    |

## Typography mood
Sharp and technical. Monospace everywhere it can be justified. For prose, a narrow geometric sans — no humanist warmth, no rounded corners. Tight letter-spacing on headings. All caps for section labels. The font stack should feel like a cockpit HUD, not a startup homepage.

- Display/headings: `'Share Tech', 'Rajdhani', 'Barlow Condensed', sans-serif`
- Body: `'Inter', 'IBM Plex Sans', 'Segoe UI', sans-serif`
- Code/labels: `'Share Tech Mono', 'JetBrains Mono', 'Fira Code', monospace`
- Letter-spacing: tight on headings (-0.02em), expanded on section labels (0.12em)
- Weight: bold headings, regular body — no medium weights

## Visual personality
Military-grade precision applied to developer tooling. Think: the instrument panel of an aircraft that does not officially exist, rendered in the color palette of a company that burned bright and disappeared at 56k baud. Angular geometry only — no rounded corners, no softness. Every decorative element must also carry information. The dark background is load-bearing: it makes the electric teal and chrome glow.

References: Enron's gradient-E confidence (color, not chaos), F-117 stealth geometry (angles, matte black), Y2K investor-deck optimism (chrome type, electric accents), WorldCom corporate-tech seriousness (grid discipline).

## Imagery style
Technical diagrams that look like they came from a classified briefing packet. Blueprint-style line art. Period Y2K corporate photography (stock photos of servers, fiber optic light trails, hands on keyboards) if found in public domain. Geometric SVG illustrations preferred over photography — angular, high-contrast, dark background. No stock-photo smiling businesspeople. No clip art.

For public domain artwork sourcing: search for US government technical illustrations, NASA/DoD instrument panels, Bell Labs computing diagrams (pre-1928 or clearly PD). These pair naturally with the Y2K-stealth aesthetic.

## SVG constraints
- viewBox: `750x420` landscape (default), `600x600` square for icons
- Corner treatment: **sharp** — 0px radius. No exceptions.
- Gradient style: linear, left-to-right, subtle — opacity 0.9→0.6. Never rainbow.
- Font family: `'Share Tech Mono', 'JetBrains Mono', monospace` for labels; `'Barlow Condensed', sans-serif` for headings
- Stroke weight: 1px for grid lines, 1.5px for data elements, 2px for borders
- Grid lines: `#1a2535` — barely visible, structural only
